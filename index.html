Speaking practice engine files

This site holds open-source speech recognition files for a speaking-practice tool used in a university course. The tool downloads them once into the student's browser and runs speech recognition there, on the student's own device. Students' audio is never sent to this site or anywhere else.

There is nothing to use on this page itself. The files are plain downloads: about 56.9 MB in total (sherpa-onnx WebAssembly runtime 1.12.36, Moonshine v2 tiny English, Silero VAD). Files over 5 MB are split into numbered parts that the tool joins again; it checks the sha256 of every file and every part before use (see SHA256SUMS.txt).
